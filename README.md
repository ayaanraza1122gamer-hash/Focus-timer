Features
Focus, short break, and long break modes
Start, pause, reset, and skip
Animated SVG progress ring
Color theme that changes with each mode
Keyboard shortcut (Space to start or pause)
Particle background and confetti
Break-time mini-game (Snake)
Session stats saved with localStorage
Custom durations and notifications
Tech
HTML5, CSS3 (custom properties, transitions)
Vanilla JavaScript (DOM manipulation, timers, events)
SVG for the progress ring
Git and GitHub for version control, deployed with GitHub Pages
